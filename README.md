# Игра «Угадай слово» на Oracle SQL/PLSQL

Учебный проект: игра для двух игроков, один объясняет слово, другой угадывает. Реализована полностью на стороне БД — логика вынесена в пакет `GAME_PKG`.

## Что внутри
- 11 таблиц с продуманной схемой (FK, CHECK, индексы)
- Пакет `GAME_PKG` (12 методов)
- 10 триггеров для защиты целостности
- Функция `IS_SAME_ROOT` для проверки корня в подсказке
- Фоновое задание `DBMS_SCHEDULER` для смены раундов по таймеру
- Демо-данные: 5 тем, 128 слов
